Five steps / Cinco passos:
  1. If you used the old "Ableton RC Setlist" 0.x build, run Migrate-RC-Setlist-Data.cmd (Windows) or Migrate RC Setlist Data.command (macOS) from this kit before opening Live. It copies profiles, project-setlists, token and preferences into the new folder without touching the old one.
  2. Se você usou o antigo "Ableton RC Setlist" 0.x, rode Migrate-RC-Setlist-Data.cmd (Windows) ou Migrate RC Setlist Data.command (macOS) deste kit antes de abrir o Live. Ele copia perfis, project-setlists, token e preferências para a pasta nova sem mexer na antiga.
  3. Double-click RC-Bridge/Install-RC-Bridge.cmd (Windows) or Install RC Bridge.command (macOS) to install RC Bridge into Live's User Library.
  4. Clique duas vezes em RC-Bridge/Install-RC-Bridge.cmd (Windows) ou Install RC Bridge.command (macOS) para instalar o RC Bridge na User Library do Live.
  5. In Live: Settings › Link, Tempo & MIDI › Control Surface, choose RCBridge. Input/Output can stay None. Open RC-Setlist-1.0.0.ablx in the Extensions panel and press Start.
  6. No Live: Configurações › Link, Tempo & MIDI › Control Surface, escolha RCBridge. Input/Output podem ficar em None. Abra RC-Setlist-1.0.0.ablx no painel de Extensões e aperte Iniciar.
  7. Scan the QR code in the panel with your tablet or phone, accept the self-signed certificate once, and rehearse the en/TEST-CHECKLIST.md cases before stage use.
  8. Leia o QR code do painel com tablet ou celular, aceite o certificado autoassinado uma vez e ensaie os casos do pt-BR/TEST-CHECKLIST.md antes do uso no palco.

First connection: your browser may show ERR_CERT_AUTHORITY_INVALID because RC Setlist creates a local self-signed certificate. Continue only when the address exactly matches the IP shown in the Live panel and you are on a trusted LAN. Each browser/device may require this once.

Primeira conexão: o navegador pode mostrar ERR_CERT_AUTHORITY_INVALID porque o RC Setlist cria um certificado local autoassinado. Continue somente se o endereço for exatamente o IP mostrado no painel do Live e a rede local for confiável. Cada navegador/aparelho pode exigir isso uma vez.

Requirement / Requisito: Ableton Live 12.4.5+ Suite Beta with Extensions support, and RC Bridge (in this kit) selected as a Control Surface. Windows is the validated release path; macOS is experimental.
