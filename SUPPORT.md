# Support

Use the following channel for each kind of request:

- Installation or usage question: [GitHub Discussions](https://github.com/ntworm/rc-setlist/discussions)
- Confirmed bug: [bug report](https://github.com/ntworm/rc-setlist/issues/new?template=bug_report.md)
- Feature idea: [feature request](https://github.com/ntworm/rc-setlist/issues/new?template=feature_request.md)
- Vulnerability: follow [SECURITY.md](SECURITY.md) and report privately.

Before asking, check [docs/FAQ.md](docs/FAQ.md) and
[docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md). Include version and platform,
but remove tokens, private paths and real setlist/lyrics content from logs.

Ableton RC Setlist is maintained without a service-level agreement. Support is provided
on a best-effort basis for the newest release.
