Built for rehearsal and stage

A Live Set that reads like a show.

Ableton RC Setlist reads structured Arrangement locators, follows Live's transport and gives performers a clear browser interface without moving the source of truth out of the Live Set.

01

Locator-driven

Define songs, sections, BPM, click, counted loops, stops and transitions directly in Arrangement locators.

02

Two stage views

Use the setlist workspace for operation and the high-contrast performance view for glanceable show state.

03

Synchronized lyrics

Create, time and display authorized LRC or plain text per local profile.

04

Guarded transport

Previous and Next require a deliberate hold; quantization changes wait for confirmation from Live.

05

Show feedback

See current and next cues, tempo, meter, drift, click state and counted-loop progress.

06

Local profiles

Keep ordering, lyrics and preferences on the show computer. Export the visible tracklist as CSV.

Three-step workflow

From locators to stage.

Ableton Live remains the timeline. Ableton RC Setlist turns its locator structure into interfaces that work on a laptop, tablet or phone.

Mark the arrangement

Name the songs and sections in Live. Add optional behavior tags.

Start Ableton RC Setlist

Open the extension panel, start its local server and use the displayed URL or QR code.

Run the show

Operate the setlist and keep the performance display visible from any trusted device on the LAN.
