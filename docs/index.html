Three-step workflow

From locators to stage.

Write the show structure once in Arrangement with automation tags. RC Setlist turns that structure into operator and performer views.

01 · MARK

Set up locators in Arrangement

Drop `[stop]`, `[next]`, `[bpm]`, `[loop]`, `[click]` markers on the timeline. RC Setlist reads them as you build the Set.

02 · CONDUCT

Drive from the Stage Control

Open the browser page. Previous, Next, Jump, Quantization, Click — guarded by 500 ms holds and confirmation from Live.

03 · READ

Perform from the second view

The performer sees the next song, the current section, the synchronized lyrics and the timecode on a high-contrast display.

Install

Five steps from zero to first cue

  1. Download RC-Setlist-1.0.0.ablx from the GitHub release.
  2. Double-click the .ablx — Ableton Live installs it under ~/Music/Ableton/User Library/Packages/RC Setlist/.
  3. Restart Live. Open the RC Setlist context menu on any MIDI/Audio track and start the bridge from the Live panel.
  4. Scan the QR on the panel with your phone, or open the URL on the same computer. Stage Control loads in the browser.
  5. Open docs/INSTALL.md (or docs/pt-BR/INSTALL.md) for the migration step from a 0.x install and the macOS path of Extensions Data.

Ableton Live 12.4.5+ Suite (Beta) is required. The development Node floor is 24.16.0. The bundled RC Bridge is our fork of AbletonOSC — same protocol, distributed with the extension.
