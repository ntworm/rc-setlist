The product stays anchored to Ableton Live. The browser gives the operator and performer the information each one needs without inventing a second timeline.

Three-step workflow

From locators
to stage.

Write the show structure once in Arrangement with automation tags. Ableton RC Setlist turns that structure into operator and performer views. [bpm] [click] [loop] [stop] [next] [skip]

Built for rehearsal and stage

A Live Set that reads like a show.

The interface mirrors the functions that ship in v0.4.1. No fictional dashboard metrics and no show content bundled with the extension.

01 · STRUCTURE

Locator-driven setlist

Turn Arrangement markers into ordered songs and sections with optional automation tags.

02 · SAFETY

Guarded transport

Previous and Next require a deliberate hold. Jump and quantization feedback wait for confirmation from Live.

03 · LYRICS

Synchronized words

Create, time, edit and display authorized LRC or plain text inside local show profiles.

04 · FEEDBACK

Current and next cues

See song and total duration, section, loop progress, stable bar/beat, BPM and click state at a glance.

05 · SHOW DATA

Saved setlists and export

Keep multiple setlists inside the current Live Set, preserve local ordering and lyrics, recover deleted profiles, and export CSV.

06 · NETWORK

Local browser access

Open Stage Control or the read-only Performance view from a trusted laptop, tablet or phone on the LAN.

Release 0.4.1

Install, rehearse, verify.

Ableton RC Setlist requires Ableton Live 12.4.5+ Suite (Beta) with Extensions support and the external AbletonOSC Control Surface. Windows is validated; macOS remains experimental for this release.

Installation guideWhat is newAbletonOSC
  • Install the single Ableton-RC-Setlist-0.4.1.ablx package
  • Install AbletonOSC separately from its upstream project
  • Start the local server from Extensions in Live
  • Open Stage Control or Performance on a trusted LAN
  • Rehearse transport, cues, click and lyrics before stage use
